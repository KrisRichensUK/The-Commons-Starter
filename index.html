ABOUT THIS STARTER

Small by design.

This is a static HTML, CSS and JavaScript starter. Posts are stored only in the current browser using localStorage. There is no authentication, moderation service, analytics, CMS, BoundProof or AffixIO integration. It is intended as a clean foundation for your own community.
